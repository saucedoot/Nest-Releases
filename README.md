# Nest — Your desktop, organized

Download and install **Nest** for **Windows 11 (64-bit)** from the **[Releases](https://github.com/saucedoot/Nest-Releases/releases/latest)** tab.

## How to install

1. Open **[Releases](https://github.com/saucedoot/Nest-Releases/releases/latest)** and click **Nest-Setup-1.1.1.exe** to download it.
2. Double-click **Nest-Setup-1.1.1.exe**. (No unzipping, no scripts, no .NET install, and no administrator password required.)
3. **One-time Windows warning:** Because this setup file is not signed with a paid certificate, Windows SmartScreen will show **"Windows protected your PC"**. Click **More info**, then click **Run anyway**.
4. Click **Install**, then **Finish**. Setup copies Nest into %LocalAppData%\Nest\App and starts it automatically.

## Quick start

- **Create a folder:** Right-click an empty spot on your desktop and click **New Nest folder** (on Windows 11, click **Show more options** first if needed), type a name, and press Enter.
- **Add or remove shortcuts:** Drag desktop or File Explorer shortcuts (.lnk or .url) into the open folder panel. Click any item once to launch it, or drag a desktop shortcut out of the panel to return it to its desktop spot.

## Good to know

- **Windows 11 (64-bit) only:** Windows 10 and ARM PCs have not been tested.
- **Hidden shortcuts setting:** Desktop shortcuts inside a Nest folder stay hidden on the desktop only while File Explorer's **"Show protected operating system files"** setting is turned **off** (the normal Windows default). If that setting is turned on, Nest shows a one-time notice at startup.
- **Quit vs. Uninstall:**
  - **Quit** (click or right-click the Nest icon in the hidden tray area near your clock → **Quit**) puts your hidden shortcuts back on the desktop for now and keeps your saved folders for the next time Nest starts.
  - **Uninstall** (Windows **Settings → Apps → Installed apps → Nest → Uninstall**) puts all hidden shortcuts back on the desktop, removes Nest's startup and desktop menu entries, and removes %LocalAppData%\Nest.
- **Not included in 1.1.1:** Dropping a shortcut onto a closed folder icon (open the folder first and drag into the panel), creating a folder by dragging one desktop shortcut onto another, and Windows 10 support.
